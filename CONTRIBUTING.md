# Contributing

Thanks for helping improve OneFileMP3Player.

## Development

```bash
php -S 127.0.0.1:8000
```

Open <http://127.0.0.1:8000> with a test audio library.

## Before submitting a pull request

- Keep changes focused and explain their purpose.
- Test browser navigation and playback.
- Test playlist, search, shuffle, loop, and tree-play.
- Check mobile and desktop layouts.
- Consider directory traversal, escaping, and exposure of private files.
- Update documentation when behavior or configuration changes.
